# Black and gold mobile identity
Original supplied 1024x1536 artwork is encoded as WebP without cropping. Home uses a single 2:3 image, max width 320, followed by the existing catalogue callback. Carousel and its automatic timers are removed.
Shared theme tokens use charcoal, champagne gold, warm ivory and brown; semantic success/error colors remain. Navigation uses charcoal and gold. Legacy token names and all functional handlers remain.
Updater runs responsive artwork tests, existing reference Home and address tests before building and installing with adb -r.
Flutter runtime validation must run on the developer Windows machine; local checks here cover Dart syntax and asset integrity.
